## 2. 화면 구성 (5개 화면)

### 화면 목록
| # | 화면명 | URL | 설명 |
|---|--------|-----|------|
| 1 | 온보딩/정보입력 | `/` | 첫 방문 시 금연 정보 입력 |
| 2 | 대시보드 (홈) | `/dashboard` | 메인 화면, 핵심 정보 표시 |
| 3 | 건강 타임라인 | `/health` | 건강 회복 단계 상세 |
| 4 | 업적/배지 | `/achievements` | 달성 배지 목록 |
| 5 | 설정 | `/settings` | 정보 수정, 리셋 |

## 3. 화면별 상세 기능 명세

### 3.1 온보딩/정보입력 화면 (`/`)

#### 화면 목적
- 첫 방문 사용자의 흡연 정보 수집
- 금연 시작 동기부여

#### 화면 플로우
```
┌─────────────────────────────────────┐
│         🚭 금연 챌린지               │
│                                     │
│   "오늘부터 새로운 시작입니다"        │
│                                     │
│  ┌─────────────────────────────┐   │
│  │ 금연 시작일                   │   │
│  │ [2024년 12월 16일      ▼]   │   │
│  └─────────────────────────────┘   │
│                                     │
│  ┌─────────────────────────────┐   │
│  │ 하루 평균 흡연량              │   │
│  │ [    20    ] 개비            │   │
│  └─────────────────────────────┘   │
│                                     │
│  ┌─────────────────────────────┐   │
│  │ 담배 한 갑 가격               │   │
│  │ [   4,500  ] 원              │   │
│  └─────────────────────────────┘   │
│                                     │
│  ┌─────────────────────────────┐   │
│  │      [ 금연 시작하기 ]        │   │
│  └─────────────────────────────┘   │
│                                     │
└─────────────────────────────────────┘
```

#### 입력 필드
| 필드명 | 타입 | 기본값 | 유효성 검사 |
|--------|------|--------|-------------|
| 금연 시작일 | Date | 오늘 | 미래 날짜 불가 |
| 하루 흡연량 | Number | 20 | 1-100 범위 |
| 담배 가격 | Number | 4,500 | 1,000-20,000 범위 |

#### 동작
- 입력 완료 → LocalStorage 저장 → 대시보드 이동
- 이미 데이터 있으면 → 바로 대시보드 이동

### 3.2 대시보드 (홈) 화면 (`/dashboard`)

#### 화면 목적
- 금연 현황 한눈에 파악
- 핵심 지표 실시간 표시
- 충동 대처 빠른 접근

#### 화면 레이아웃

```
│    │         23초              │   │     (실시간 업데이트)
│    │                           │   │
│    └───────────────────────────┘   │
│                                     │
│    ┌─────────┬─────────┬────────┐  │
│    │  💰     │   🚬    │   ⏰   │  │

│                                     │
│    ┌───────────────────────────┐   │

│                                     │
├─────────────────────────────────────┤
│  🏠    ❤️    🏆    ⚙️              │  ← 하단 네비게이션
│  홈   건강  업적  설정              │
└─────────────────────────────────────┘
```

#### 실시간 계산 로직
```javascript
// 금연 시간
const quitTime = Date.now() - quitStartDate;
const days = Math.floor(quitTime / (1000 * 60 * 60 * 24));
const hours = Math.floor((quitTime % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));
const minutes = Math.floor((quitTime % (1000 * 60 * 60)) / (1000 * 60));
const seconds = Math.floor((quitTime % (1000 * 60)) / 1000);

// 절약 금액
const cigarettesNotSmoked = days * dailyCigarettes + (hours / 24) * dailyCigarettes;
const moneySaved = (cigarettesNotSmoked / 20) * packPrice;

// 연장된 수명 (담배 1개비 = 11분 수명 단축 기준)
const lifeRegained = cigarettesNotSmoked * 11; // 분 단위
```

#### 상호작용
| 요소 | 탭 동작 |
|------|---------|
| 건강 상태 카드 | → 건강 타임라인 화면 이동 |
| 충동 대처 버튼 | → 충동 대처 모달 열기 |
| 하단 네비게이션 | → 각 화면 이동 |

## 4. 데이터 구조 (LocalStorage)

### 저장 데이터 스키마
```typescript
// 담배 종류 타입
type TobaccoType = 'cigarette' | 'liquid_ecig' | 'heated_ecig';

// 금연 모드 타입
type QuitMode = 'cold_turkey' | 'gradual';

interface UserData {
  // 기본 설정
  quitMode: QuitMode;              // 금연 모드
  quitDate: string;                // ISO 8601 형식 "2024-12-04T09:00:00"
  tobaccoTypes: TobaccoType[];     // 사용 담배 종류 (복수 선택 가능)

  // 담배 종류별 설정
  cigaretteConfig?: {              // 일반 담배 설정
    cigarettesPerDay: number;      // 하루 흡연량 (개비)
    pricePerPack: number;          // 한 갑 가격
    cigarettesPerPack: number;     // 한 갑 개비 수 (기본 20)
  };

  liquidEcigConfig?: {             // 액상 전자담배 설정
    puffsPerDay: number;           // 하루 퍼프 수
    liquidVolume: number;          // 액상 용량 (ml)
    liquidPrice: number;           // 액상 가격
    expectedDays: number;          // 예상 사용일
    nicotineContent?: number;      // 니코틴 함량 (mg/ml, 선택)
  };

  heatedEcigConfig?: {             // 궐련형 전자담배 설정
    sticksPerDay: number;          // 하루 사용량 (개비)
    pricePerPack: number;          // 한 갑 가격
  };

  // 점진적 금연 설정 (gradual 모드일 때)
  gradualPlan?: {
    targetQuitDate: string;        // 목표 완전 금연일
    currentPhase: number;          // 현재 단계 (1부터 시작)
    totalPhases: number;           // 총 단계 수
    dailyLimit: number;            // 현재 일일 허용량
    reductionType: 'count' | 'nicotine'; // 감량 방식 (개비 수 or 니코틴)
  };

  // 흡연 기록 (점진적 금연 시)
  smokingLogs: SmokingLog[];       // 흡연 기록

  // 통계
  cravingLogs: CravingLog[];       // 충동 기록
  checkInLogs: CheckInLog[];       // 일일 체크인 기록
  triggerLogs: TriggerLog[];       // 트리거 분석용 기록

  // 설정
  settings: {
    darkMode: boolean;
    largeText: boolean;
    notifications: {
      enabled: boolean;
      dailyCheckIn: string;        // HH:mm 형식
      motivational: boolean;
    };
  };

  // 백업/복원
  lastBackup?: string;             // 마지막 백업 시간

  // 버전 (마이그레이션용)
  version: string;
}

// 흡연 기록 (점진적 금연용)
interface SmokingLog {
  timestamp: string;               // 흡연 시각
  tobaccoType: TobaccoType;        // 담배 종류
  amount: number;                  // 양 (개비 또는 퍼프)
  trigger?: string;                // 트리거 (선택)
  mood?: string;                   // 기분 (선택)
}

interface CravingLog {
  timestamp: string;               // 충동 발생 시각
  overcome: boolean;               // 극복 여부
  duration: number;                // 극복까지 걸린 시간 (초)
  trigger?: string;                // 트리거
  copingMethod?: string;           // 대처 방법
}

// 일일 체크인 기록
interface CheckInLog {
  date: string;                    // YYYY-MM-DD
  mood: 'great' | 'good' | 'okay' | 'bad' | 'terrible';
  cravingLevel: number;            // 1-5 스케일
  notes?: string;                  // 메모 (선택)
  smokeFree: boolean;              // 금연 유지 여부
}

// 트리거 분석용 기록
interface TriggerLog {
  timestamp: string;
  trigger: string;                 // 트리거 종류
  situation: string;               // 상황 설명
  outcome: 'smoked' | 'resisted';  // 결과
}
```

### LocalStorage 키
```javascript
const STORAGE_KEY = 'smoking-habit-data';

// 저장
localStorage.setItem(STORAGE_KEY, JSON.stringify(userData));

// 불러오기
const userData = JSON.parse(localStorage.getItem(STORAGE_KEY));
```

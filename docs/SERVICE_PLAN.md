# 🚭 Smoking Habit - 금연 챌린지 웹앱 서비스 기획서

## 1. 서비스 개요

### 1.1 서비스명
**Smoking Habit** (스모킹 해빗) - "습관을 바꾸는 첫 걸음"

### 1.2 서비스 목표
- 금연을 시도하는 사람들에게 **무료**로 동기부여와 진행 상황 추적 제공
- **남녀노소 누구나** 쉽게 사용할 수 있는 직관적인 UI/UX
- 과학적 데이터 기반의 건강 회복 정보 제공

### 1.3 타겟 사용자
- 금연을 시작하려는 흡연자
- 금연 중인 사람 (동기부여 필요)
- 금연에 여러 번 실패한 사람 (재도전)

## 3. 핵심 기능

### 3.1 메인 대시보드
```
┌─────────────────────────────────────┐
│     🎉 금연 시작한 지               │
│        12일 5시간 32분              │
│                                     │
│  ┌─────────┐ ┌─────────┐ ┌────────┐│
│  │ 💰      │ │ 🚬      │ │ ⏰     ││
│  │ 54,000원│ │ 240개비 │ │ +2일   ││
│  │ 절약    │ │ 안 핀   │ │ 수명   ││
│  └─────────┘ └─────────┘ └────────┘│
│                                     │
│  [오늘의 건강 회복 상태]            │
│  ████████████░░░░ 72%               │
│  "폐 기능이 개선되고 있어요!"       │
└─────────────────────────────────────┘
```

### 3.2 건강 회복 타임라인
금연 후 신체 변화를 시각적으로 표시:

| 시간 | 변화 | 아이콘 |
|------|------|--------|
| 20분 | 혈압과 맥박 정상화 | ❤️ |
| 8시간 | 혈중 산소 정상화 | 🫁 |
| 24시간 | 심장마비 위험 감소 시작 | 💪 |
| 48시간 | 미각/후각 회복 시작 | 👃 |
| 72시간 | 기관지 이완, 호흡 개선 | 🌬️ |
| 1주일 | 니코틴 갈망 감소 | 🧠 |
| 1개월 | 폐 기능 30% 향상 | 📈 |
| 3개월 | 혈액순환 개선 | 🩸 |
| 6개월 | 기침/숨가쁨 감소 | 😮‍💨 |
| 1년 | 심장병 위험 50% 감소 | ❤️‍🩹 |
| 5년 | 뇌졸중 위험 = 비흡연자 | 🧠 |
| 10년 | 폐암 위험 50% 감소 | 🎗️ |
| 15년 | 심장병 위험 = 비흡연자 | 🏆 |

### 3.3 절약 금액 계산기
- 하루 흡연량 입력
- 담배 가격 입력 (기본값: 4,500원)
- 실시간 절약 금액 표시
- 절약 금액으로 살 수 있는 것들 시각화
  - ☕ 커피 N잔
  - 🍔 햄버거 세트 N개
  - ✈️ 해외여행 N번 (연간)

### 3.4 흡연 충동 대처
**"담배 피고 싶어요" 버튼 클릭 시:**
1. 심호흡 가이드 (4-7-8 호흡법)
2. 물 마시기 리마인더
3. 짧은 산책 제안
4. 동기부여 명언
5. 지금까지의 성과 리마인드
6. 충동 기록 (패턴 분석용)

### 3.5 일일 체크인
- 매일 금연 유지 확인
- 오늘의 기분/컨디션 기록
- 연속 금연일 배지 시스템
- 주간/월간 리포트

### 3.6 배지 & 업적 시스템
```
🥉 첫 걸음     - 금연 시작
🥈 하루 완주   - 24시간 금연
🥇 일주일     - 7일 금연
💎 한 달      - 30일 금연
👑 석 달      - 90일 금연
🏆 일 년      - 365일 금연
```

### 3.7 실패 시 재시작
- 비난 없는 격려 메시지
- "다시 시작하기" 버튼
- 이전 기록 보존 (통계용)
- 실패 패턴 분석 및 조언

## 4. UI/UX 설계 원칙

### 4.1 디자인 원칙
1. **심플함** - 불필요한 요소 최소화
2. **큰 글씨** - 노년층도 읽기 쉬운 폰트 크기
3. **명확한 색상 대비** - 접근성 고려
4. **직관적 아이콘** - 텍스트 + 아이콘 병행
5. **원터치 접근** - 주요 기능 1~2탭 내 도달

### 4.2 색상 팔레트
```
Primary:    #10B981 (민트 그린 - 건강/회복)
Secondary:  #3B82F6 (블루 - 신뢰/안정)
Accent:     #F59E0B (오렌지 - 성취/에너지)
Background: #F9FAFB (밝은 회색)
Text:       #111827 (거의 검정)
```

### 4.3 반응형 디자인
- 모바일 퍼스트 (주 사용 환경)
- 태블릿/데스크톱 지원
- PWA로 앱처럼 사용 가능

## 5. 기술 스택

### 5.1 프론트엔드
- **Next.js 14** (App Router)
- **TypeScript** - 타입 안정성
- **Tailwind CSS** - 빠른 스타일링
- **Framer Motion** - 부드러운 애니메이션

### 5.2 데이터 저장
- **LocalStorage** - 기본 데이터 저장
- **선택적 클라우드 동기화** (추후)

### 5.3 배포
- **Vercel** - 무료 호스팅
- **PWA** - 오프라인 지원

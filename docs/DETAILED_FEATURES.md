## 2.3 담배 종류별 기능 차별화

> 각 담배 종류에 따라 대시보드, 통계, 건강 회복 정보가 맞춤화됩니다.

### 2.3.1 대시보드 표시 차별화

| 항목 | 일반 담배 | 액상 전자담배 | 궐련형 전자담배 |
|------|-----------|---------------|-----------------|
| **단위 표시** | "개비" | "퍼프" | "개비" |
| **절약 계산** | 개비당 가격 | ml당 가격 | 개비당 가격 |
| **일일 기록** | 담배 1개비씩 기록 | 퍼프 수 기록 또는 세션 기록 | 담배 1개비씩 기록 |
| **아이콘** | Cigarette | Cloud | Flame |

### 2.3.2 건강 회복 타임라인 차별화

#### 일반 담배 사용자
```
20분  → 혈압/맥박 정상화
8시간 → 혈중 일산화탄소 정상화
24시간 → 심장마비 위험 감소 시작
48시간 → 미각/후각 회복 시작
72시간 → 기관지 이완, 호흡 개선
1주일 → 니코틴 완전 배출
1개월 → 폐 기능 30% 향상
...
```

#### 액상 전자담배 사용자
```
20분  → 혈압/맥박 안정화
2시간 → 니코틴 수치 감소 시작
24시간 → 니코틴 금단 증상 최고조 (극복 시 감소)
48시간 → 미각 회복 시작
72시간 → 폐 내 화학물질 배출 시작
1주일 → 기침/가래 감소
2주일 → 폐 섬모 기능 회복 시작
1개월 → 폐 염증 감소
...
```
> 전자담배 특성상 타르는 없지만 니코틴, 프로필렌글리콜, 향료 등의 화학물질 배출이 핵심

#### 궐련형 전자담배 사용자
```
20분  → 혈압/맥박 정상화
8시간 → 혈중 일산화탄소 감소 (연초보다 낮은 수치에서 시작)
24시간 → 니코틴 수치 감소
48시간 → 미각/후각 회복 시작
72시간 → 호흡 개선
1주일 → 니코틴 금단 증상 완화
1개월 → 폐 기능 개선 시작
...
```
> 궐련형은 연초와 유사하지만 타르가 적어 회복 메시지가 약간 다름

### 2.3.3 절약 금액 계산 방식

#### 일반 담배
```typescript
const dailySaving = (dailyCigarettes / cigarettesPerPack) * pricePerPack;
// 예: (20개비 / 20개비) * 4,500원 = 4,500원/일
```

#### 액상 전자담배
```typescript
const dailyCost = (liquidPrice / expectedDays);
// 예: 15,000원 / 7일 = 2,142원/일
// 퍼프 기반: (dailyPuffs / totalPuffsPerBottle) * liquidPrice
```

#### 궐련형 전자담배
```typescript
const dailySaving = (dailySticks / sticksPerPack) * pricePerPack;
// 예: (20개비 / 20개비) * 4,500원 = 4,500원/일
```

### 2.3.5 점진적 금연 - 담배 종류별 감량 전략

#### 일반 담배
- 개비 수 기반 감량
- 흡연 간격 늘리기
- 특정 상황 금연 (식후, 커피 등)

#### 액상 전자담배
- 니코틴 농도 단계적 감소 (9mg → 6mg → 3mg → 0mg)
- 일일 퍼프 수 제한
- 사용 시간대 제한

#### 궐련형 전자담배
- 개비 수 기반 감량 (일반 담배와 유사)
- 기기 사용 시간 제한 설정

## 4. 점진적 금연 모드 (Gradual Reduction) - 연구 기반 설계

### 4.0 연구 기반 설계 원칙

> **임상 연구 결과:**
> - 점진적 금연 + 니코틴 대체요법 병행 시 금연 성공률 2배 증가
> - "스케줄드 스모킹" 방식이 금단증상과 흡연욕구 감소에 효과적
> - 주 단위 명확한 목표 설정 + 자주 체크인이 성공률 높임
> - 단순히 개수만 줄이는 것보다 **흡연 간격 늘리기**가 더 효과적

### 4.1 플로우

```
[담배 종류 선택] → [현재 흡연 패턴 분석] → [맞춤 감량 계획 생성] → [매일 기록 + 코칭] → [완전 금연 전환]
```

```javascript
// 점진적 감량 계획 생성
function createReductionPlan(currentAmount, targetDays) {
  const plan = [];
  const dailyReduction = currentAmount / targetDays;

  for (let day = 0; day <= targetDays; day++) {
    const allowed = Math.max(0, Math.round(currentAmount - (dailyReduction * day)));
    plan.push({
      day: day,
      date: addDays(new Date(), day),
      allowedAmount: allowed,
      isQuitDay: allowed === 0
    });
  }

  return plan;
}
```

```
3. "액상 전자담배" 선택

7. 오늘 허용량 대비 진행률 확인
```

```javascript
// 주간 통계 계산
function calculateWeeklyStats(startDate, endDate) {
  const checkIns = getCheckInsInRange(startDate, endDate);
  const cravings = getCravingsInRange(startDate, endDate);

  return {
    // 금연 일수
    smokFreeDays: calculateSmokFreeDays(startDate, endDate),

    // 절약 금액
    moneySaved: calculateMoneySaved(startDate, endDate),

    // 안 핀 담배
    cigarettesAvoided: calculateCigarettesAvoided(startDate, endDate),

    // 기분 분포
    moodDistribution: calculateMoodDistribution(checkIns),

    // 평균 충동 강도
    avgCravingLevel: calculateAvgCraving(checkIns),

    // 충동 강도 추이 (일별)
    cravingTrend: calculateCravingTrend(checkIns),

    // 충동 극복 횟수
    cravingsOvercome: cravings.filter(c => c.overcome).length,

    // 체크인 완료율
    checkInRate: (checkIns.length / 7) * 100
  };
}

// 기분 분포 계산
function calculateMoodDistribution(checkIns) {
  const distribution = {};
  checkIns.forEach(c => {
    distribution[c.mood] = (distribution[c.mood] || 0) + 1;
  });

  const total = checkIns.length;
  return Object.keys(distribution).map(mood => ({
    mood,
    count: distribution[mood],
    percentage: Math.round((distribution[mood] / total) * 100)
  }));
}
```

```javascript
  break_time: { emoji: "☕", label: "휴식시간" },
  boredom: { emoji: "😴", label: "심심함" },
  driving: { emoji: "🚗", label: "운전중" },
  social: { emoji: "👥", label: "사람들과" },
  other: { emoji: "❓", label: "기타" }
};

// 시간대 분석
function analyzeTimePattern(cravings) {
  const timeSlots = {
    morning: { range: [6, 12], count: 0 },
    lunch: { range: [12, 14], count: 0 },
    afternoon: { range: [14, 18], count: 0 },
    evening: { range: [18, 21], count: 0 },
    night: { range: [21, 24], count: 0 }
  };

  cravings.forEach(c => {
    const hour = new Date(c.timestamp).getHours();
    for (const [slot, data] of Object.entries(timeSlots)) {
      if (hour >= data.range[0] && hour < data.range[1]) {
        data.count++;
        break;
      }
    }
  });

  return timeSlots;
}
```

```javascript
// 알림 권한 요청
async function requestNotificationPermission() {
  if (!("Notification" in window)) {
    console.log("이 브라우저는 알림을 지원하지 않습니다.");
    return false;
  }

  if (Notification.permission === "granted") {
    return true;
  }

  if (Notification.permission !== "denied") {
    const permission = await Notification.requestPermission();
    return permission === "granted";
  }

  return false;
}

// 로컬 알림 스케줄링 (Service Worker 활용)
async function scheduleNotification(type, time, message) {
  const registration = await navigator.serviceWorker.ready;

  // 알림 데이터 저장
  const notifications = JSON.parse(localStorage.getItem('scheduled-notifications') || '[]');
  notifications.push({
    id: Date.now(),
    type,
    scheduledTime: time,
    message,
    shown: false
  });
  localStorage.setItem('scheduled-notifications', JSON.stringify(notifications));
}

// 아침 동기부여 메시지 생성

  const messages = [

    `${day}일간 ${day * 20}개비를 안 피웠어요! 멋져요 🚭`,

// 위험 시간대 알림 (패턴 기반)
function scheduleRiskTimeAlert() {
  const pattern = analyzeTimePattern(getCravingHistory());

  // 가장 충동이 많은 시간대 찾기
  const riskSlot = Object.entries(pattern)
    .sort((a, b) => b[1].count - a[1].count)[0];

  if (riskSlot) {
    const alertTime = riskSlot[1].range[0] - 0.5; // 30분 전
    scheduleNotification(
      'risk_alert',
      alertTime,
      `곧 충동이 올 수 있는 시간이에요. 준비되셨나요? 🛡️`

  }
```

```javascript
// 스케줄된 알림 확인 및 표시
async function checkAndShowNotifications() {
  const now = new Date();
  const currentHour = now.getHours();
  const currentMinute = now.getMinutes();

  // 저장된 알림 스케줄 확인
  const notifications = JSON.parse(
    await localforage.getItem('scheduled-notifications') || '[]'
  );

  for (const notif of notifications) {
    const scheduledTime = new Date(notif.scheduledTime);

    if (!notif.shown &&
        scheduledTime.getHours() === currentHour &&
        Math.abs(scheduledTime.getMinutes() - currentMinute) < 5) {

      await self.registration.showNotification('Smoking Habit', {
        body: notif.message,
        icon: '/icon-192.png',
        badge: '/badge-72.png',
        tag: notif.type,
        requireInteraction: false,
        actions: [
          { action: 'open', title: '앱 열기' },
          { action: 'dismiss', title: '닫기' }
        ]
      });

      notif.shown = true;
    }
  }

  await localforage.setItem('scheduled-notifications', JSON.stringify(notifications));
}

// 알림 클릭 처리
self.addEventListener('notificationclick', (event) => {

    );
```

### 18.5 원터치 공유 구현 (Web Share API)

```javascript
// 공유 버튼 클릭 시 바로 실행
async function shareNow(type = 'progress') {
  // 1. 로딩 표시
  showLoadingToast('카드 만드는 중...');

  try {
    // 2. 현재 통계 가져오기
    const stats = getCurrentStats();

    // 3. 카드 이미지 생성 (html2canvas 사용)
    const cardImage = await generateShareCard(stats, type);

    // 4. 로딩 해제
    hideLoadingToast();

    // 5. Web Share API 지원 확인 및 공유
    if (navigator.share && navigator.canShare) {
      const blob = await (await fetch(cardImage)).blob();
      const file = new File([blob], `smoking-habit-${type}.png`, {
        type: 'image/png'
      });

      // 파일 공유 가능 여부 확인
      if (navigator.canShare({ files: [file] })) {
        await navigator.share({
          title: getShareTitle(stats),
          text: getShareText(stats),
          files: [file]
        });

        showSuccessToast('공유 완료!');
        return;
      }
    }

    // 6. Web Share 미지원 시 → 바텀 시트 표시
    showShareBottomSheet(cardImage, stats);

  } catch (error) {
    if (error.name !== 'AbortError') {
      // 사용자 취소가 아닌 에러
      showErrorToast('공유 중 오류가 발생했어요');
    }
  }
}

// 공유 텍스트 생성
function getShareTitle(stats) {
  return `🚭 ${stats.days}일째 금연 중!`;
}

function getShareText(stats) {
  return `금연 ${stats.days}일차! 💰${stats.money.toLocaleString()}원 절약, 🚬${stats.cigarettes}개비 안 핌. 함께 도전해요! #금연챌린지`;
}
```

### 18.6 카드 이미지 생성 (html2canvas)

```javascript
import html2canvas from 'html2canvas';

// 공유 카드 컴포넌트를 이미지로 변환
async function generateShareCard(stats, type) {
  // 1. 임시 카드 요소 생성
  const cardElement = document.createElement('div');
  cardElement.innerHTML = getCardHTML(stats, type);
  cardElement.style.cssText = `
    position: fixed;
    left: -9999px;
    width: 540px;
    height: 540px;
  `;
  document.body.appendChild(cardElement);

  // 2. 폰트 로딩 대기
  await document.fonts.ready;

  // 3. html2canvas로 변환
  const canvas = await html2canvas(cardElement, {
    width: 540,
    height: 540,
    scale: 2,  // 고해상도
    backgroundColor: null,
    useCORS: true
  });

  // 4. 임시 요소 제거
  document.body.removeChild(cardElement);

  // 5. 이미지 데이터 반환
  return canvas.toDataURL('image/png', 1.0);
}
```

```javascript
async function copyToClipboard(text) {
  try {
    await navigator.clipboard.writeText(text);
    showSuccessToast('링크가 복사되었어요!');
  } catch {
    // 폴백: 구형 방식
    const textarea = document.createElement('textarea');
    textarea.value = text;
    document.body.appendChild(textarea);
    textarea.select();
    document.execCommand('copy');
    document.body.removeChild(textarea);
    showSuccessToast('링크가 복사되었어요!');
  }
}
```
